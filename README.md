# For Annu — Two Years of Us

A free, personalised anniversary microsite for Antra ("Annu"), dated 24 November 2026.

## Files
- `index.html` — page content and sections
- `style.css` — scrapbook / polaroid styling
- `script.js` — photo previews and celebration interaction

## Preview on your laptop
1. Extract the ZIP file.
2. Open the `annu_anniversary_website` folder.
3. Double-click `index.html` to open it in Chrome.

No installation or paid service is required.

## Add your photos
Open the website and tap/click the empty polaroid frames. Choose a photo from your device. Use **Add more photos** for extra pictures.

Privacy note: photo previews are created in your browser using local file reading. They are not uploaded to a server. They may disappear after refreshing or closing the page, so keep the original photos separately.

## Publish it free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `for-annu`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub to publish the site. Copy the Pages URL and send it to Annu.

The Google Fonts are optional; if the device is offline, the page will use fallback fonts.
